# Пробные страницы

Не входят в сборку: Vite собирает только `index.html`, а эти файлы лежат
вне корня сборки и в `dist` не попадают. Проверено `pnpm check:bundle`.

Нужны для локального замера в настоящем браузере:

```bash
pnpm --filter @extramundum/web dev -- --port 5199
pnpm render:probe                 # цифры от самого рендера + скриншот
pnpm render:probe -- --url http://127.0.0.1:5199/dev/layout.html --width 380 --height 780
```

`scene.html` — сцена без интерфейса, меряет вызовы отрисовки и кадр.
`layout.html` — настоящий экран арены, меряет переполнение и перекрытие.
`battle.html` — воспроизведение ЗАПИСАННОГО боя, без сервера и без входа.

Про `battle.html` стоит знать, зачем она есть, хотя настоящий экран арены
работает. У персонажа первого уровня нет ни трейтов, ни щита, ни предметов
(это M3), поэтому НАСТОЯЩИЙ бой не порождает ни статусов, ни блоков,
ни срабатываний трейтов: половину показа — иконки статусов с таймерами,
свёрнутые тики, отражённый урон — на нём не увидеть.

Эталонный лог из тестов эти события содержит: он порождён движком
на бойцах со школой MAG, щитом и `thorns`. Показывает его ТОТ ЖЕ код,
что и арена (`mountBattle`), — отличается только источник боя.

```bash
# ?locale=en — второй язык, ?skipMs=9000 — сразу к моменту со статусами
open http://127.0.0.1:5173/dev/battle.html?skipMs=9000
```
